# Raccourcis clavier et gestes

La touche Super porte les commandes du système ; les raccourcis d'application (Ctrl + …) ne
sont pas interceptés, sauf Ctrl + Alt + T et les combinaisons Ctrl + Alt ci-dessous.

## Fenêtres

| Action | Clavier | Geste ou souris |
|---|---|---|
| Changer de fenêtre | Alt + Tab, Alt + Maj + Tab | — |
| Fenêtres de la même application | Alt + ` | — |
| Fermer la fenêtre | Super + Q | bouton de gauche |
| Agrandir ou restaurer | Super + ↑ | bouton de droite, double-clic sur la barre de titre |
| Restaurer ou réduire | Super + ↓ | clic du milieu sur la barre de titre (réduire) |
| Réduire | Super + M | — |
| Masquer l'application | Super + H | — |
| Moitié, deux tiers puis tiers | Super + ← ou →, répété | glisser vers le bord |
| Tiers | Super + Alt + 1, 2, 3 | — |
| Quarts | — | glisser vers un coin |
| Centrer (64 % de la largeur) | Super + C | — |
| Tuilage automatique | Super + T | — |
| Échanger avec la principale (en tuilage) | Super + Entrée | bouton d'agrandissement d'une fenêtre de la pile, ou la glisser sur la principale |
| Échanger deux fenêtres (en tuilage) | — | glisser l'une sur l'autre |
| Afficher le bureau | Super + D | — |

## Espaces de travail

| Action | Clavier | Geste |
|---|---|---|
| Vue d'ensemble | Super + S, Ctrl + Alt + ↑ ou ↓ | 3 doigts vers le haut ou le bas, coin haut-gauche |
| Espace précédent ou suivant | Super + Ctrl + ← ou →, Ctrl + Alt + ← ou → | 3 ou 4 doigts à gauche ou à droite |
| Envoyer la fenêtre sur l'espace N | Super + Maj + 1…9 | — |

## Bureau

| Action | Clavier |
|---|---|
| Lanceur | Super, Super + Espace |
| Centre de contrôle | Super + A |
| Calendrier et notifications | Super + N |
| Historique du presse-papiers | Super + V |
| Terminal | Super + Entrée (hors tuilage), Ctrl + Alt + T |
| Verrouiller | Super + L |
| Widgets devant les fenêtres, puis derrière | Super + W, Échap |
| Modifier les widgets | clic droit sur le bureau |
| Capture de tout l'écran | Impr. écran |
| Capture d'une zone | Maj + Impr. écran |
| Quitter le bureau | Ctrl + Alt + Retour arrière |
| Terminal virtuel | Ctrl + Alt + F1…F12 |
