# Raccourcis clavier et gestes

La touche Super porte les commandes du système ; les raccourcis d'application (Ctrl + …) ne
sont pas interceptés, sauf les attributions système indiquées ci-dessous. Les raccourcis
peuvent être consultés et modifiés dans Paramètres → Clavier ; leurs changements sont appliqués
sans redémarrer. L'écran s'assombrit progressivement avant le verrouillage et la mise en veille.

## Fenêtres

| Action | Clavier | Geste ou souris |
|---|---|---|
| Changer de fenêtre | Alt + Tab, Alt + Maj + Tab | — |
| Fenêtres de la même application | Alt + ` | — |
| Fermer la fenêtre | Super + Q | bouton × (le plus à droite) |
| Agrandir ou restaurer | Super + ↑ | bouton du milieu, double-clic sur la barre de titre |
| Restaurer ou réduire | Super + ↓ | clic du milieu sur la barre de titre (réduire) |
| Réduire | Super + M | bouton – (à gauche des trois) |
| Masquer l'application | Super + H | — |
| Garder la fenêtre toujours au-dessus des autres (ou arrêter) | Super + Maj + T | clic droit sur l'icône du Dock → « Toujours au-dessus » |
| Moitié, deux tiers puis tiers | Super + ← ou →, répété | glisser vers le bord |
| Tiers | Super + Alt + 1, 2, 3 | — |
| Quarts | — | glisser vers un coin |
| Centrer (64 % de la largeur) | Super + C | — |
| Tuilage automatique | Super + T | — |
| Échanger avec la principale (en tuilage) | Super + Entrée | bouton d'agrandissement d'une fenêtre de la pile, ou la glisser sur la principale |
| Échanger deux fenêtres (en tuilage) | — | glisser l'une sur l'autre |
| Afficher le bureau | Super + D | coin bas-droit |
| Remettre la dernière fenêtre réduite | Ctrl + Alt + M | — |
| Zoomer (Lecteur PDF, Visionneuse, applis qui le gèrent) | Ctrl + molette | pincer à deux doigts sur le pavé tactile |

## Espaces de travail

| Action | Clavier | Geste |
|---|---|---|
| Vue d'ensemble | Super + S, Ctrl + Alt + ↑ ou ↓ | 3 doigts vers le haut ou le bas, coin haut-gauche |
| Espace précédent ou suivant | Super + Ctrl + ← ou →, Ctrl + Alt + ← ou → | 3 ou 4 doigts à gauche ou à droite |
| Envoyer la fenêtre sur l'espace N | Super + Maj + 1…9 | — |

## Bureau

| Action | Clavier |
|---|---|
| Lanceur | Super |
| Centre de contrôle | Super + A |
| Calendrier et notifications | Super + N |
| Historique du presse-papiers | Super + V |
| Terminal | Super + Entrée (hors tuilage), Ctrl + Alt + T |
| Verrouiller | Super + L |
| Dialogue d'arrêt | Super + Échap |
| Widgets devant les fenêtres, puis derrière | Super + W, Échap |
| Modifier les widgets | clic droit sur le bureau |
| Raccourci sur le bureau : ajouter une application / un dossier | clic droit sur son icône (Dock ou menu Applications) → « Ajouter au bureau » ; dans Fichiers, clic droit → « Ajouter au bureau » ; clic droit sur le bureau → « Ajouter un dossier au bureau… » |
| Raccourci sur le bureau : ouvrir / retirer | clic / clic droit → « Retirer du bureau » (toute la sélection si l'icône en fait partie) |
| Icônes du bureau : sélectionner plusieurs | tirer un rectangle depuis le bureau vide ; Ctrl + clic (ou Maj + clic) pour en ajouter ou en retirer une ; un clic à côté oublie la sélection |
| Raccourci sur le bureau : déplacer dans une autre case (sur une autre icône : elles échangent leurs places) ; une icône sélectionnée emmène tout le groupe | glisser à la souris |
| Icônes du bureau plus grandes / plus petites (chacune garde sa place sur l'écran) | Ctrl + molette vers le haut / le bas, ou pincer sur le pavé tactile, ou clic droit sur le bureau → « Agrandir les icônes » / « Réduire les icônes » |
| Capture : écran de capture (Sélection, Écran ou Fenêtre) | Impr. écran |
| Capture : ouvrir directement en mode Sélection | Maj + Impr. écran, ou Super + Maj + S (touche de capture Lenovo sans Fn) |
| Capture : prendre l'image / fermer | Entrée ou Espace / Échap |
| Capture : copier le texte d'une zone | Impr. écran → « Texte », tracer la zone, Entrée |
| Changer de disposition clavier (aussi sur l'écran verrouillé, avec indication à l'écran) | Super + Espace |
| Écran de connexion : compte précédent / suivant | ↑ / ↓ ou Tab |
| Quitter le bureau | Ctrl + Alt + Retour arrière |
| Terminal virtuel | Ctrl + Alt + F1…F12 |

Les coins actifs (haut-gauche : vue d'ensemble, bas-droit : bureau) se choisissent dans
Paramètres → Bureau et dock. Le bouton d'alimentation physique suit Paramètres → Énergie
(veille par défaut, rien, ou dialogue d'arrêt) ; les boutons dessinés ouvrent toujours le
dialogue.
